# Edge-case regression tests and fixes

Created: 11-10-2026-04-59-23 (Asia/Qyzylorda, UTC+05:00).

## Goal and scope

Investigate failure boundaries across the equity research application, add deterministic offline regressions,
fix demonstrated failures and repeat verification until the agreed regression matrix and all required gates pass.
Live providers and paid model/search execution remain separate. No API endpoints, SSE names or report schemas changed.

## Reproductions and fixes

The starting suites passed 380 backend and 75 frontend tests, with no Pyright errors. New focused tests first
reproduced 16 backend and nine frontend failures. Follow-up review reproduced four malformed-enrichment failures
and four formatting failures; these were fixed before final verification.

| Boundary | Demonstrated behavior before the fix | Result and reasoning |
|---|---|---|
| Quote numbers | Negative Yahoo current prices overrode valid alternate prices; oversized integers raised OverflowError | Select positive finite Yahoo prices; treat overflowing conversions as unusable. KASE still uses only native price and returns quote unavailable for unusable prices |
| Provider parsing | One peer's malformed business summary aborted its batch | Parse within the provider error boundary, exclude the bad peer and retain valid candidates without caching the failure |
| KASE enrichment | Malformed Yahoo text fields could discard a valid native quote during later parsing | Validate enrichment text before transferring fields; preserve the native quote and an enrichment diagnostic |
| History | NaN/infinity were admitted and later serialized as null numeric points | Omit unusable numbers and nonpositive closes; retain zero accounts and negative earnings. Malformed dates degrade history through ProviderError while preserving the quote |
| Financial arithmetic | Nonfinite medians, percentage scaling, moving averages and upside could overflow or distort scoring | Return unavailable derived evidence, neutral factor scores and missing-value text in Python and TypeScript |
| Cache identity | Structurally valid data under another ticker's key was accepted | Add synchronous accept_cached parity with afetch; evict mismatched quote/report/snapshot/comps-target identities. Native caches require KASE provenance, USD quotes, no alias ranges and no trading history |
| Producer lifecycle | Empty/early EOF emitted no final error; a producer could run beyond its terminal event | Emit one terminal pipeline error for premature EOF, stop at the first terminal event and close the producer; retain shutdown draining and cancellation |
| Browser stream | Valid JSON with malformed nested values could crash the reducer or render another ticker's report | Validate event fields, section shapes, array elements, finite numbers and target identity before dispatch. Keep the existing controlled retry message and ignore stale callbacks |
| Report routes | Percent-containing decoded parameters threw URIError in both page rendering and metadata | Use Next.js parameters directly, retain ticker-keyed report remounts and route invalid ticker requests through existing validation |

Valid older Yahoo reports remain readable without the newer optional financial-currency/enrichment/quote provenance
fields. Unknown additional event fields remain compatible. Native KASE records with foreign history or absent native
provenance are intentionally rejected rather than presented as exchange data.

## Test coverage

Added 40 backend and 32 frontend test cases to the existing suites and focused new producer/event/route tests.
Coverage includes quote alternates and overflow, peer isolation, missing/invalid history, finite arithmetic and
formatting, exact TTL expiry, failed-loader retry, synchronous acceptance predicates, wrong-key data, legacy
reports, native cache boundaries, confidence and word-limit boundaries, stream refusal/truncation after partial
text, one-time usage recording, late subscribers, terminal cleanup, malformed event objects and nested arrays,
cross-ticker events, class-share identity, KASE provenance, navigation and superseded callbacks.

Provider recordings, fake model output, injected clocks and synchronization events keep the additions offline
and deterministic; the new concurrency cases use no timing-dependent sleeps.
