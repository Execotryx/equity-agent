# Native KASE USD quotes and underscore ticker support

Creation: 11-10-2026-00-13-55 (Asia/Qyzylorda).

## Changes and reasoning

- Backend and frontend accept underscores while retaining trimming, uppercasing, class-share handling,
  a leading-letter requirement and the ten-character limit. This lets native exchange identifiers reach
  form navigation, SSE requests, shared-run keys, cached-report lookup and provider requests unchanged.
- `data/kase.py` supplies the production router used by API, CLI, evaluation recording, raw fixture
  recording and exchange probes. It requests public KASE security JSON with a ten-second timeout.
  Responses and HTTP error bodies close after each call; no persistent HTTP client was introduced.
- Native quotes validate symbol, issuer, security type and USD currency. Mapped names and instrument ISINs
  are checked against the registry; CORE_KZ retains a verified quote-only identity. Only positive finite
  `price` is accepted. Unknown, recognized-but-unquoted, unsupported and provider failures stay distinct.
  Foreign prices, close_price, bids/offers, annual closes and 52-week ranges never substitute.
- Explicit Yahoo mappings record issuer identities, expected ISINs and source URLs. Both Halyk GDR units
  represent 40 common shares; other initial mappings use matching one-share units. London aliases preserve
  .IL verbatim. Supplied alias ISINs, names, symbols and currencies are checked before enrichment.
- Company descriptions, sector, annual accounts and unitless ratios may be enriched. Failures preserve
  native quotes and add diagnostics. Financial currency is independent of trading currency in UI and
  agent payloads. Unknown currency suppresses monetary history, including older saved reports; model
  defaults still deserialize those reports. Existing demo recordings and live evidence remain untouched.
- Compatible USD accounts permit native/source price-ratio adjustments to P/E, forward P/E and P/B;
  dividend yield uses the inverse ratio. Native capitalization uses verified USD source quote
  capitalization and compatible units. USD analyst targets use documented unit conversions and a
  cross-listing estimate label. No FX conversion or native EV-based ratios are introduced.
- Native annual price history and ranges are unavailable, keeping momentum neutral with a visible
  diagnostic. Eligible issuers use explicit SEC aliases while retaining filing provenance. Target aliases
  are excluded before peer provider access, including when a peer quote would fail.
- Optional quote/enrichment provenance and financial-currency contracts are generated into TypeScript.
  Quote source, official casing and provider timestamp appear beside the price; issuer financial sources
  and reporting currency appear beside financials. Endpoints and SSE event names are unchanged.
- README, AGENTS.md, implementation guidance and OpenSpec requirements describe the new boundaries.
  Recorded KASE fixtures cover shares, receipts and unquoted CORE_KZ. Synthetic protocol fixtures cover
  404, unsupported instruments/currencies, malformed responses, timeouts and outages.
- Verified current Yahoo financialCurrency=USD was added to the five existing US target fixtures.
  Their previous observed quote/history values were preserved. Golden differences contain only the
  financial currency and nullable provenance fields; previous agent inputs match exactly. UI fixtures
  were regenerated and normalized to preserve original data, event ordering and volatile timing fields.
